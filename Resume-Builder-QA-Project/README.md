# Resume Builder QA Project

## Overview
This repository is a portfolio case study demonstrating an end-to-end QA approach for a candidate Resume Builder web application. It covers profile management, resume-building workflows, validation, CRUD operations, data persistence, usability, and synchronization between **Edit Profile** and **Build Resume**.

## Portfolio Integrity
This project is presented as a sample QA engagement. Confirmed defects will be supported by observed application behavior and evidence. Illustrative execution data or sample defects will be clearly labeled and will not be represented as production findings.

## Modules
- Personal Information
- Professional Snapshot
- Skills and Tools
- Education
- Work Experience
- Projects
- Resume Upload and Management
- Build Resume
- Cross-Module Synchronization
- Common Validation and UI Behavior

## Testing Approach
- Requirement-based functional testing
- Positive, negative, boundary, and validation testing
- CRUD and data-persistence testing
- Cross-module synchronization testing
- UI consistency and usability review
- Regression planning
- Evidence-based Jira-style defect reporting

## Planned Next Phase
Phase 2 will add module-level test scenarios and detailed test cases. The RTM will then be updated with scenario IDs and test case IDs so that every requirement has visible coverage.
